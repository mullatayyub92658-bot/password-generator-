# 🔑 Password Generator

A simple and secure password generator built with Python. This project randomly selects from letters, numbers, and special symbols to create a strong, unpredictable password based on your preferred length.

## 🚀 How it Works
* Asks the user to enter their desired password length.
* Combines lowercase letters, uppercase letters, digits, and special characters.
* Generates a completely randomized secure string.

## 🛠️ Built With
* Python 3
* `random` module
